# future.med 

**future.med** (Futuremed Connect) is India's first curated medtech ecosystem and Collective. 

This repository contains the static website for future.med, built with a focus on modern, premium design aesthetics to showcase the brand's mission, ecosystem, and perspectives.

## Overview

The website serves as the digital front door for future.med, highlighting its unique position in the medical technology landscape. It is designed to connect early-stage medtech startups, clinical institutions, and investors—helping to build structured commercialisation pathways for medical innovations in India and globally.

## Key Sections

- **Home**: The main landing page introducing the future.med ecosystem, value proposition, and commercialisation models.
- **The Collective**: Details about the curated network of experts, clinical institutions, and industry leaders.
- **Perspectives**: A collection of insights, articles, and thought leadership on medtech commercialisation, product-market fit, and industry trends.

## Technologies Used

- **HTML5**: Semantic markup for robust content structure.
- **CSS3**: Vanilla CSS with custom properties (variables) for a premium, maintainable design system without external frameworks.
- **JavaScript**: Vanilla JS for dynamic elements, smooth scrolling, and UI interactions.

## Design Philosophy

The design leverages a sophisticated aesthetic using:
- A curated color palette (deep navy blues, elegant gold accents, and clean off-white backgrounds).
- Modern typography pairing (*Cormorant Garamond* for elegant display headings and *DM Sans* for highly readable body text).
- Subtle gradients, clean lines, and micro-animations to create a dynamic, premium user experience.
